# @gameguild/emception-toolchain

Versioned browser toolchain artifacts for Emception. The package owns the
schema-v2 manifest, compressed sysroot bundles, generated Emscripten glue, and
their matching WebAssembly ABI profiles.

Use `@gameguild/emception-browser` to load and execute these artifacts. The
legacy `emception/cdn/*` export is retained temporarily for compatibility.
