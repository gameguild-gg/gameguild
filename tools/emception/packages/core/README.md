# @emception/core

Runtime-agnostic core for [emception](https://github.com/gameguild-gg/gameguild/tree/main/tools/emception). Types, error hierarchy, presets, VFS, tool registry, build resolver, test engine, `RuntimeAdapter`.

**Phase 0 alpha.** API surface only — no working implementation yet. See [`tools/emception/docs/dx-overhaul-plan.md`](../../docs/dx-overhaul-plan.md).
