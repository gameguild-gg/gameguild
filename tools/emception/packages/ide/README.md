# @emception/ide

Reactive `<Ide>` React 19 component + `<emception-ide>` custom-element wrapper (light DOM). For [emception](https://github.com/gameguild-gg/gameguild/tree/main/tools/emception).

Promoted from `@gameguild/emception-ui` (`packages/emception`). All panels (canvas / terminal / workspace / docking / tabs / file-explorer) are toggleable.

**Phase 0 alpha** — skeleton only. Source migration in Phase 0.2; reactive rewrite in Phase 8.
