# @emception/browser

Browser runtime adapter for [emception](https://github.com/gameguild-gg/gameguild/tree/main/tools/emception). Spawns Web Workers, persists workspaces in IndexedDB, helpers for OffscreenCanvas + SDL/ImGui, COI preflight.

**Phase 0 alpha** — skeleton only. Implementation migrates from `tools/emception/src/` in Phase 0.2.
