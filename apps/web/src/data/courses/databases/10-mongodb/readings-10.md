# Week 10 — MongoDB Readings & Resources

## Official Documentation

### Getting Started

- [MongoDB Manual](https://www.mongodb.com/docs/manual/)
  - Official documentation covering all MongoDB features

- [MongoDB University](https://learn.mongodb.com/)
  - Free online courses on MongoDB fundamentals and advanced topics

- [BSON Specification](https://bsonspec.org/)
  - Technical specification for Binary JSON format

### Schema Design

- [Data Modeling Introduction](https://www.mongodb.com/docs/manual/core/data-modeling-introduction/)
  - Official guide to MongoDB schema design principles

- [Schema Design Patterns](https://www.mongodb.com/blog/post/building-with-patterns-a-summary)
  - Building with Patterns series (Attribute, Bucket, Subset, etc.)

- [Embedding vs Referencing](https://www.mongodb.com/docs/manual/core/data-model-design/)
  - When to embed vs reference documents

### CRUD Operations

- [MongoDB CRUD Operations](https://www.mongodb.com/docs/manual/crud/)
  - Comprehensive guide to Create, Read, Update, Delete

- [Query Operators Reference](https://www.mongodb.com/docs/manual/reference/operator/query/)
  - Complete list of query operators ($gte, $in, $regex, etc.)

- [Update Operators Reference](https://www.mongodb.com/docs/manual/reference/operator/update/)
  - All update operators ($set, $inc, $push, $pull, etc.)

### Aggregation Pipeline

- [Aggregation Pipeline](https://www.mongodb.com/docs/manual/core/aggregation-pipeline/)
  - Official aggregation framework documentation

- [Aggregation Pipeline Stages](https://www.mongodb.com/docs/manual/reference/operator/aggregation-pipeline/)
  - Reference for all pipeline stages ($match, $group, $lookup, etc.)

- [Practical MongoDB Aggregations](https://www.practical-mongodb-aggregations.com/)
  - Free online book with real-world aggregation examples
