## Tech Demo

::: info

It is highly recommended to enroll into the game [here](https://itch.io/jam/gpr340-25) in order to submit your tech demo. But it is not required.

:::

You have to implement a tech demo featuring your game AI algorithm. The tech demo should be a playable version of the game with the AI algorithm implemented.

::: warning

In order to make the life of your testers easier and safer, you have to publish it as WebGL build. Executing random executable files is a security risk, so make sure to only allow the execution of the game AI algorithm.

Suggested game engines that support WebGL builds:

- [Unity](https://unity.com/) - Any version
- [Unreal Engine](https://www.unrealengine.com/) - Last version that supports WebGL build is **4.23**.
- [Godot](https://godotengine.org/) - Any version, but if you want to use dotnet, you have to use version **3.6** or lower.
- [GameMaker](https://gamemaker.io/) - Any version

Suggest me other game engines that support WebGL builds.

:::

## Post writeup

Your post should include the following:

- At least 3 references. It can be books, articles, or websites;
- A description of the game AI algorithm implemented;
- Which games this algorithm can be applied to;
- If a game mechanic involves the algorithm, discuss how it is implemented;
- Length should be around 600 words;
- Your post should reference your very own technical demo;
- Use diagrams to explain your concepts as much as needed. Suggestions: [Code2flow](https://code2flow.com/) and [Mermaid](https://mermaid.live/).

## Presentation

- The goal of the presentation is to teach the class that specific topic;
- Your audience is the class, so target the level of content to be around yours;
- Duration: around 10 minutes;
- You may use any presentation tool you like, but I recommend [Google Slides](https://www.google.com/slides/) for simplicity, easy to share and multi user editing.
- This is a formal presentation, be prepared to answer questions from the audience.
- You may use your tech demo in your presentation.

## Submission

- The presentation;
- The link for the blog post (linkeding, medium, etc.)
- The link for the tech demo (itch.io, github pages, etc.)
