## Tech Demo

::: info

Enroll into the game [here](https://itch.io/jam/gpr340-25).

:::

You have to implement a tech demo featuring your game AI algorithm. The tech demo should be a playable version of the game with the AI algorithm implemented.

::: warning

In order to make the life of your testers easier and safer, you have to publish it as WebGL build. Executing random executable files is a security risk, so make sure to only allow the execution of the game AI algorithm.

Suggested game engines that support WebGL builds:

- [Unity](https://unity.com/) - Any version
- [Unreal Engine](https://www.unrealengine.com/) - Last version that supports WebGL build is **4.23**.
- [Godot](https://godotengine.org/) - Any version, but if you want to use dotnet, you have to use version **3.6** or lower.
- [GameMaker](https://gamemaker.io/) - Any version

Suggest me other game engines that support WebGL builds.

:::
