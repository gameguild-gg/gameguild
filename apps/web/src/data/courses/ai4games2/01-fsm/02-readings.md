# Week 01 Readings - FSM, Behavior Trees & Decision Architectures

---

## Required Readings

| #   | Reading                                                                                                                                                           | Time   | Covers                                                      |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | ----------------------------------------------------------- |
| 1   | Robert Nystrom, [State Pattern](https://gameprogrammingpatterns.com/state.html) - Game Programming Patterns                                                       | 30 min | FSM basics, state pattern, HFSMs, pushdown automata         |
| 2   | Champandard & Dunstan, [Behavior Tree Starter Kit](https://www.gameaipro.com/GameAIPro/GameAIPro_Chapter06_The_Behavior_Tree_Starter_Kit.pdf) (PDF) - Game AI Pro | 45 min | Selectors, sequences, parallels, decorators, implementation |
| 3   | Ian Millington, **AI for Games (3rd Ed.)**, Chapter 5 - ISBN 9781138483972                                                                                        | 45 min | Decision trees, state machines, behavior trees              |
