## Overview

This week teams **exchange projects** for structured code review and final play-testing. You will also submit your **technical essay draft**.

## Peer Evaluation

### As a Reviewer

- You will be assigned another team's project.
- **Code Review** — Read through their AI implementation. Look for: code organization, algorithm correctness, documentation quality, and potential bugs.
- **Play-Test** — Play their build and evaluate the AI behavior: does it achieve what the proposal claimed?
- Fill out the **peer evaluation rubric** (provided in class) with constructive feedback.

### As a Team Being Reviewed

- Ensure your code repository is accessible to reviewers.
- Include a README explaining how to build/run the project and where the AI code lives.

## Deliverables

1. **Peer evaluation feedback** — Completed rubric for the team you reviewed (due Sunday).
2. **Technical essay draft** — A draft of your individual writeup (2000–3000 words). See the [Final Project writeup requirements](../09-break/final-project.md#post-writeup). This draft does not need to be final, but should be substantially complete.
3. **Code freeze** — Final code pushed to repository by Wednesday 2026/04/22.
