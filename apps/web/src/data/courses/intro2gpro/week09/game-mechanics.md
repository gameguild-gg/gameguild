# Game Mechanics

Game mechanics are the rules and its consequences one can expect from the game. It can be expressed in simple rules, systems, actions and events. In summary they are "**Methods** invoked by the **agents** to change the **game state**" [reference](https://www.gamestudies.org/0802/articles/sicart).

## Activity

Explore game mechanics catalogs, select some of them, and use them into your pitch for the game you are planning to develop.

## References

- 300 Mechanics in 300 Days: https://www.squidi.net/three/. One game mechanic idea per day for 300 days with brief descriptions
- BoardGameGeek Mechanics Browser: https://boardgamegeek.com/browse/boardgamemechanic. Comprehensive taxonomy of board game mechanisms with definitions and examples
- Game Mechanic Explorer: https://gamemechanicexplorer.com/. JavaScript/Phaser examples with source code from basic to advanced
- Giant Bomb Concepts Wiki: https://www.giantbomb.com/concepts/. Thousands of video game concepts with game examples
- TVTropes: https://tvtropes.org/pmwiki/pmwiki.php/Main/GameMechanics. Extensive catalog organized by category with examples
- Game Mechanics Wiki: https://gamemechanics.fandom.com/wiki/Game_Mechanics_Wiki. Community wiki cataloging gaming concepts across platforms
