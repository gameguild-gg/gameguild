## Overview

This week teams **exchange projects** for structured code review and final testing. You will also submit your **technical essay draft**.

## Peer Evaluation

### As a Reviewer

- You will be assigned another team's project.
- **Code Review** — Read through their networking implementation. Look for: code organization, protocol correctness, error handling, documentation quality, and potential bugs (e.g., buffer overflows, race conditions, unhandled disconnections).
- **Test** — Run their build and evaluate the networking behavior: does it achieve what the proposal claimed? How does it handle edge cases (disconnection, high latency, malformed packets)?
- Fill out the **peer evaluation rubric** (provided in class) with constructive feedback.

### As a Team Being Reviewed

- Ensure your code repository is accessible to reviewers.
- Include a README explaining:
  - How to build and run the project
  - Where the networking code lives
  - How to test with multiple clients
  - Any known issues or limitations

## Deliverables

1. **Peer evaluation feedback** — Completed rubric for the team you reviewed (due Sunday).
