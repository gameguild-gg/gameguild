## Overview

This week your team must demonstrate that the **core networking is working**. The goal is to show tangible progress — not a polished application, but clear evidence that the central networking mechanism functions.

## Deliverables

Provide **one** of the following:

1. **Testable Build** — Publish a build with instructions for others to run it (e.g., GitHub repo with README, Docker Compose setup, or hosted demo). Even a minimal prototype with placeholder UI is fine as long as the networking runs.

2. **Video Demo** — Record a 2–5 minute video showing the networking in action. Narrate what is happening and point out the network communication. Upload to YouTube (unlisted is fine) or share via Google Drive.

## What "Core Networking Working" Means

- The fundamental networking mechanism (e.g., client-server connection, P2P discovery, message exchange) produces correct results.
- It runs across at least two processes or machines (not just loopback-only tests).
- You can describe what it does, where it succeeds, and where it still needs work.

::: tip

Do not worry about polish, UI, or edge cases yet. Focus on getting the network loop running: **connect → send → receive → respond**.

:::
