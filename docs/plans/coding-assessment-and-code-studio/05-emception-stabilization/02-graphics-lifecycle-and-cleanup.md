## Repair scope

`EMC-GAP-003`, `CS-RUNTIME-GRAPHICS` and the channel regression are linked in
[FINDINGS.md](./FINDINGS.md). Start with the pinned actual SDL bundle and original
five-cycle oracle. The prior authorized fix removes 26 registrations, not the
remaining anonymous document listeners. Native stop working is not full disposal.

Review the smallest neutral lifecycle correction with the artifact owner before
touching a recipe or upstream source. Do not patch global event methods, erase
other consumers' listeners, rewrite downloaded glue/manifests or revive an iframe
redesign without a new decision. Use normal source/build/provenance controls for
an approved artifact change. Preserve frozen versions needed by past attempts.

The editor/terminal and canvas are separate execution capabilities, not separate
academic policies. Verify each retained graphical preset explicitly. Raylib and
Allegro are unverified here; SDL evidence cannot enable them. Official graphics
grading remains unavailable unless separately specified and authorized; this
phase does not invent screenshot grading or equate canvas pixels with a score.

## Exit

The original five-cycle required oracles return exit 0 without relaxed listener
or memory allowances. A failed cleanup stays open; unverified future profiles
stay explicitly unavailable. Actual affected production desktop/mobile and
instructor/learner views are inspected separately from the calibration fixture.
Regression tests preserve legacy single-sink callers, separate fd 1/2 output,
idempotent stop and the unaffected IDE/UI. Record owner/human acceptance.
