## Final acceptance

- Reconcile all entries against parts 03/04, including findings discovered after
  this plan was written. A matching ID and source link are mandatory.
- Confirmed defects in retained/offered behavior are fixed and regressions pass.
  No arbitrary score, empty success, required skip, permissive fallback,
  broadened timeout or altered oracle substitutes for a correction.
- Optional RAM/compound/profile/assistance work has an explicit owner-reviewed
  implement/defer/reject disposition and user-facing availability. A real
  unresolved correctness/safety defect remains blocking, not optional.
- Revalidate part 04's official scalar-function and stdio journey using real
  authorized personas and actual pinned source/artifacts. Local port/IDE proof
  cannot replace it. Human and canonical capability review remain explicit.
- Review affected instructor/learner and preserved-consumer tasks. Record exact
  commands, IDs/counts, exits, artifacts, resource observations and reviewer.
- Prepare separately scoped, tested part 05 PRs to `develop`; coordinate any
  upstream repair with its owner and reconcile/retest before integration. Do
  not change the integrated parts 01-04 or per-language PR strategy.

## Handoff

[part 06 language expansion](../06-emception-capability-and-language-review.md)
start its common baseline. That baseline rechecks the corrected current Emception,
not a pre-repair checkout. Each language still needs its independent decision,
implementation, tests and PR. Code Studio remains part 07 and conditional.

Update [state.md](./state.md), [FINDINGS.md](./FINDINGS.md), the root roadmap and
shared ADRs compactly. Keep historical failures. This plan never authorizes a
push, merge, release publication or independent IDE deployment by itself.
